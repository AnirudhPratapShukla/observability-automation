# Part 5 - Question 4: Grok Scripting & Log Parsing

## Overview

This solution uses Logstash Grok filters to parse custom application log
formats generated by the rbcapp1 application.

The parsed events are sent to Elasticsearch for centralized search and
analysis.

## Files

- `logstash.conf` - Logstash pipeline configuration.
- `grok-patterns.md` - Documentation of the Grok patterns.
- `sample-app.log` - Sample application log input.
- `README.md` - Setup and verification instructions.

## Log Formats

The pipeline supports the application log formats identified in
`sample-app.log`.

Grok patterns extract useful fields such as:

- Timestamp
- Log level
- Service/application name
- Message
- Host information where available

The detailed patterns and their target formats are documented in
`grok-patterns.md`.
