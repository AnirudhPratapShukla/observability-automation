# ELK / Observability Engineer Technical Assignment

## Overview

This repository contains my solutions for the ELK / Observability Engineer
technical assignment for the rbcapp1 application monitoring environment.

The implementation covers Python service monitoring, REST API integration,
infrastructure automation, operational automation, Docker/Kubernetes,
ELK observability, data processing, OpenTelemetry, and security/compliance
architecture.
